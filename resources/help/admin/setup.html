Первый запуск и подключение к серверу

Перед первым запуском на сервере (это может быть и компьютер администратора) должен быть установлен PostgreSQL версии 14 или новее штатным установщиком. При первом запуске программы открывается мастер настройки с двумя вариантами.

Первичная настройка сервера

Укажите адрес и порт сервера (обычно localhost и 5432), имя суперпользователя (postgres) и его пароль, заданный при установке PostgreSQL. Программа создаст:

  • учётную запись приложения (по умолчанию sedm_app) с паролем, проверяемым по протоколу SCRAM-SHA-256;
  • базу данных (по умолчанию sedm) и схему данных sedm — учётной записи приложения доступна только эта схема.

Пароль учётной записи приложения программа предлагает сама (кнопка «Другой» — новый вариант). Запишите его: он понадобится при настройке компьютеров дегустаторов. Пароль суперпользователя нигде не сохраняется.

Подключение к настроенной базе

Если база уже создана (например, на другом компьютере администратора), укажите адрес сервера, имя базы, учётную запись приложения и её пароль.

Пароль администратора

Затем задайте пароль администратора — не менее 6 символов, хотя бы одна буква и одна цифра. В базе данных хранится только его криптографический хэш (bcrypt). При каждом запуске программа запрашивает этот пароль; после пяти ошибок подряд вход блокируется на 60 секунд.

Параметры подключения хранятся в файле настроек пользователя; пароль учётной записи приложения записан в защищённом виде (средствами Windows). Изменить параметры можно командой Файл → Подключение к БД.
