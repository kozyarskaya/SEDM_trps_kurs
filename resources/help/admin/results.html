Итоги и итоговая ведомость

Как считаются баллы и места

  • Итоговый балл дегустатора по образцу — среднее арифметическое четырёх оценок (вид и цвет, консистенция, запах и аромат, вкус).
  • Средний балл образца — среднее итоговых баллов всех дегустаторов, которые сохранили по этому образцу все четыре оценки; округляется до сотых.
  • Места распределяются внутри номинации по убыванию среднего балла. Равные баллы получают одно место, следующее место не пропускается: 1, 2, 2, 3. Образцы без полных оценок места не получают.

В окне выберите номинацию: таблица показывает место, шифр, участника, регион, итоговые баллы каждого дегустатора и средний балл. Первое место выделено цветом.

Экспорт ведомости XLSX (Ctrl+E)

Файл Excel из двух листов:

  • «Итоги» — по номинациям: место, шифр, ФИО и регион участника, итоговые баллы дегустаторов, средний балл, число полных оценок;
  • «Детализация» — каждая оценка: номинация, шифр, участник, команда, дегустатор, четыре оценки, итоговый балл, примечание, время сохранения.

Ведомость можно формировать в любой момент (например, промежуточную). Каждая выгрузка записывается в журнал действий.
