# СЭДМ — программная система экспертной дегустации мёда

Курсовая работа по дисциплине «Технология разработки программных систем».
МГТУ им. Н. Э. Баумана, кафедра «Компьютерные системы и сети» (ИУ6).
Выполнила: С. И. Козярская, группа ИУ6-73Б. Руководитель: С. С. Данилюк. Москва, 2026.

СЭДМ автоматизирует закрытую (по шифрам) органолептическую оценку образцов мёда на конкурсах и
дегустациях: реестр участников, регистрация образцов со случайными уникальными шифрами, корзины
образцов и дегустационные команды, оценивание по четырём критериям, расчёт средних баллов и мест,
итоговая ведомость в Excel, резервные копии и журнал действий.

Система состоит из двух программ на общей библиотеке:

- **«СЭДМ — администратор»** (`sedm_admin.exe`) — подготовка и проведение дегустации, мониторинг, итоги;
- **«СЭДМ — дегустатор»** (`sedm_taster.exe`) — оценивание образцов, интерфейс для возрастных пользователей.

Данные хранятся на сервере PostgreSQL 14 и новее; программы работают в локальной сети без Интернета.

## Технологии

C++17, Qt 5.15.2 (Widgets, SQL, PrintSupport, Svg), PostgreSQL 14+ (клиентская библиотека libpq),
QXlsx (MIT), crypt_blowfish (bcrypt), CMake + Ninja, MinGW 8.1 (x64 и x86), Qt Test, Inno Setup 6.

## Структура

| Каталог | Содержимое |
|---|---|
| `src/core` | общая библиотека: предметная область (`domain`), безопасность (`security`), доступ к данным (`data`), импорт и экспорт CSV/XLSX (`io`), прикладные сервисы (`services`) |
| `src/widgets` | общие элементы интерфейса: тема, сообщения, справка, окно подключения, шкала оценки |
| `src/admin` | программа администратора |
| `src/taster` | программа дегустатора |
| `tests` | автоматические тесты (Qt Test): модульные, интеграционные, интерфейса, производительности |
| `resources` | справка (HTML), схема базы данных `sql/schema.sql`, значки, оформление |
| `3rdparty` | QXlsx, crypt_blowfish |
| `tools/demo` | генератор демонстрационных данных `sedm_demo` |
| `installer` | сценарий установщика Inno Setup и сценарий сборки дистрибутива |

## Сборка

Нужны Qt 5.15.2 для MinGW 8.1, CMake, Ninja и PostgreSQL 14 или новее (из его комплекта
берётся `libpq`).

```powershell
$env:PATH = 'C:\Qt\Tools\mingw810_64\bin;C:\Qt\5.15.2\mingw81_64\bin;C:\Program Files\PostgreSQL\18\bin;' + $env:PATH
cmake -S . -B build-x64 -G Ninja -DCMAKE_BUILD_TYPE=Release -DCMAKE_PREFIX_PATH=C:\Qt\5.15.2\mingw81_64
cmake --build build-x64
```

Программы — в `build-x64/bin`. Дистрибутив для Windows x86 и x64 (`SEDM-1.0.0-setup.exe`) собирает
`installer/build_installer.ps1`.

## Запуск

При первом запуске программа администратора открывает мастер первичной настройки: он создаёт на
сервере базу `sedm`, учётную запись приложения `sedm_app` (SCRAM-SHA-256, доступ только к схеме
`sedm`) и пароль администратора. Программа дегустатора при первом запуске спрашивает адрес сервера
и пароль учётной записи приложения. Демонстрационные данные создаёт `sedm_demo.exe`.

## Тесты

```powershell
$env:SEDM_TEST_PGPORT = '5432'; $env:SEDM_TEST_PGSUPERUSER = 'postgres'
$env:SEDM_TEST_PGSUPERPASS = Read-Host 'Пароль postgres'
$env:QT_QPA_FONTDIR = 'C:\Windows\Fonts'
cd build-x64/bin
.\tst_domain.exe; .\tst_services.exe; .\tst_taster_ui.exe; .\tst_admin_ui.exe; .\tst_performance.exe
```

Тесты с базой данных создают временные базы и удаляют их после работы. Результат: 63 теста
пройдены; время отклика — сотые доли секунды (предел ТЗ — 2 с), итоговая ведомость из 500 образцов
и 50 команд — 0,2 с (предел — 30 с), память клиента — 35 МБ (предел — 512 МБ).
